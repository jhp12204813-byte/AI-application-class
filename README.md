# AI Application Class

AI Application 수업 실습 및 과제를 정리한 저장소입니다.

## Week 02 - Python 데이터 처리 기초

Python을 이용한 차량 주행 로그 데이터 처리 및 시각화 실습입니다.

### 학습 내용

- NumPy 배열 생성 및 연산
- Indexing / Slicing
- Boolean Indexing
- Broadcasting / Vectorization
- NumPy 통계 함수
- Pandas DataFrame
- 데이터 Filtering
- GroupBy를 이용한 집계
- 결측치 탐지 및 처리
- 이상치 탐지
- Min-Max Normalization
- matplotlib을 이용한 데이터 시각화

### 실습 데이터

24시간 합성 차량 주행 로그 데이터를 사용합니다.

주요 데이터:
- 시간 (Hour)
- 차량 속도 (Speed)
- 연비 (Fuel Efficiency)
- 도로 유형 (Road Type)

### Visualization

다음 그래프를 이용하여 데이터를 분석합니다.

- Line Plot : 시간대별 평균 속도
- Bar Plot : 시간대별 과속 발생 횟수
- Scatter Plot : 속도와 연비의 관계
- Histogram : 차량 속도 분포
